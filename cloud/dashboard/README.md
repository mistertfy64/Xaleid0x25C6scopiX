# แดชบอร์ด Vital Sign Monitor

หน้าเว็บแบบ static นี้ไม่ต้องติดตั้งไลบรารีเพิ่มเติม ใช้บัญชีผู้ดูแลเพื่อเข้าสู่ระบบและอ่านข้อมูลจาก API เดิมที่ `/login` และ `/measurements` โทเค็นผู้ดูแลจะอยู่ในหน่วยความจำเท่านั้น หน้าเว็บแสดงอัตราการเต้นของหัวใจ ค่า SpO₂ อุณหภูมิร่างกาย อุณหภูมิเครื่อง กราฟแนวโน้มที่เลือกตัวชี้วัดและช่วงเวลาได้ (1, 6 หรือ 24 ชั่วโมง) และประวัติการวัดล่าสุด 12 รายการ โดยรีเฟรชข้อมูลอัตโนมัติทุก 30 วินาที

เปิดเซิร์ฟเวอร์จากโฟลเดอร์หลักของ repository:

```sh
python -m http.server 8080 --directory dashboard
```

เปิด `http://localhost:8080` แล้วกรอก URL ของ Cloud API ที่ใช้ HTTPS พร้อมชื่อผู้ใช้และรหัสผ่านของบัญชีผู้ดูแล สำหรับ origin นี้ ให้ตั้งค่า `VSM_CORS_ORIGINS=http://localhost:8080` ในไฟล์ `.env` ของ Cloud แล้วเริ่ม backend ใหม่ เมื่อนำไปใช้งานจริง ให้เปิดหน้าเว็บผ่าน HTTPS และเพิ่ม origin ของหน้าเว็บนั้นใน `VSM_CORS_ORIGINS`

## ตัวอย่างข้อมูลสำหรับทดสอบ UI

เปิด `http://localhost:8080/?demo=1` หรือ `http://127.0.0.1:8080/?demo=1` เพื่อดู Dashboard พร้อมข้อมูลจำลอง 12 รายการ โหมดนี้ทำงานเฉพาะบน localhost และไม่เรียก API หรือบันทึกข้อมูลลงฐานข้อมูล ข้อมูลบนหน้าจอเป็นข้อมูลตัวอย่าง ไม่ใช่ข้อมูลจริง
